# Keep the first build local and content-file based

The first release is a prototype, so use a React/TypeScript client built with Vite and a small Express/TypeScript API for the optional Race Engineer, and keep evidence and mission content in versioned local files. Do not add accounts, persistent user data, a content administration system, or a database to this release; this keeps the demo simple while preserving an API boundary for a later provider or content source.
